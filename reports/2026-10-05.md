# Initial three-party exit test — October 5, 2026 (America/Denver)

Result: 10 model tests and the private Bitcoin regtest covenant experiment passed.
Node source: `7d365603415422bf5f71bbae6ad9b54cb038471e`.

The experiment funded a three-party output with 301,000 test sats. Recovery
transactions were saved, fsynced and read back before broadcasting either funding
transaction. After a node restart and the 12-block relative delay, the opening
recovery transaction paid 100,000 sats to each member, consuming 1,000 sats in fees.
No participant signatures or fresh cooperation were required at exit time.
Early exits and changed recovery allocations were rejected. Three missing-signature
cases, a wrong signer and tampered cooperative outputs were also rejected.
The node used its default 32-byte CSFS message limit and RDTS policy.

This is a script-level experiment, not a full offline-participant network test.
It also deliberately verified that an old fully signed allocation remains valid
after signing a new allocation. Consequently **latest-state unilateral recovery
is unfinished and funded balance updates remain disabled**. Fixed opening refunds
must not be treated as safe exits for a channel with changing balances.

Remaining work: safe stale-state invalidation/replacement, interrupted signing,
independent participant recovery journals, fee bumping, conditional-payment exits,
and an isolated Lightning adapter. Fixed test keys must never fund public outputs.
No production services or public signet state were changed.

Transaction IDs and assertions are in [the machine-readable results](2026-10-05-regtest.json).
These are private-regtest transactions, not public explorer transactions.
